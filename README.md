# RetroDiva – Frontend

Frontend de tienda virtual RetroDiva, enfocado en moda retro y vintage.  
Desarrollé principalmente la sección **About**, implementando diseño responsivo y experiencia de usuario atractiva.

## Tecnologías usadas
- **HTML5**  
- **CSS3**  
- **JavaScript**  
- Diseño responsivo para diferentes tamaños de pantalla

## Descripción
RetroDiva es una tienda virtual de moda retro. Este proyecto corresponde al desarrollo del **frontend**, donde se implementó la sección “About” para mostrar información de la marca, misión y visión, usando buenas prácticas de diseño web y experiencia de usuario.
